## Source and regression rules

1. Reimplement product behaviors in Wapas’s current Python/FastAPI and SQLModel/SQLite stack.
2. Do not import either project as a runtime dependency or copy their UI, brand assets, fixtures, or code.
3. Keep demo/synthetic data separate from merchant records.
4. Adapt only verified ideas: structured intent, deterministic resolution, confirmation, persistent inbox, polling fallback, and demand aggregation from persisted outcomes.
5. Preserve the existing Wapas revenue-recovery workflow and its tests.
