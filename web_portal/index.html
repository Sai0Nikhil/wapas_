Integration doctor

Calls each configured service for real: Paytm status API, LLM, Sarvam speech round trip, Telegram, database, worker. Same as python -m app.doctor.

Execution boundary

Agentreads context through 3 read-only tools, recommends one of 4 options + timing. Cannot import the gateway, messaging or Telegram (tested).
Policydeterministic, fail-closed YAML: limits, confidence floor, opt-outs, quiet hours, duplicates, refunds never automatic. Decides AUTO / OWNER / BLOCK.
Executorsends exactly once per idempotency key, verifies with Paytm's status API, credits only the exact amount owed.
Ownersigned, expiring approval buttons bound to the decision shown. No answer = nobody contacted.
